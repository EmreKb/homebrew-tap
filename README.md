# EmreKb's Homebrew Tap

This is a [Homebrew](https://brew.sh/) tap for my macOS applications.

## Available Casks

- **KVick**: A lightweight macOS menu bar utility to store and copy frequently used text snippet.
∏
## Installation

To add this tap to your Homebrew, run:

```bash
brew tap EmreKb/tap
```

## Usage

After tapping, you can install the available casks. For example, to install KVick:

```bash
brew install --cask kvick
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
